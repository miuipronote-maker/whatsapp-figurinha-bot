
# WhatsApp Figurinha Bot

Bot de WhatsApp que transforma vídeos recebidos e links compatíveis em vídeos quadrados MP4 com áudio.

## Recursos

- Recebe vídeos pelo WhatsApp.
- Processa links públicos compatíveis.
- Converte vídeos para formato quadrado.
- Preserva o áudio.
- Limita o vídeo a 12 segundos.
- Envia o resultado automaticamente no mesmo chat.

## Tecnologias

- Node.js
- Baileys
- FFmpeg
- yt-dlp

## Instalação

```bash
npm install
npm start
```

## Observação

O funcionamento depende da disponibilidade dos serviços externos e da compatibilidade do link enviado.
